## My first project - an open-source 3D engine in Python.

I got bored while sitting at home during the break. 
So I wrote this over the course of a couple of days.
Feel free to use it however you like.

## Installing and launching

Just clone this repository, then run in your terminal:
```bash
python -m pip install -r requirements.txt
python main.py
```
Or, if you are Windows user, double-click on "run.bat" file.

## Hotkeys
F3 - debug screen
F7 - debug render modes
F11 - fullscreen
Esc - settings screen
Tab - fly / walk mode
